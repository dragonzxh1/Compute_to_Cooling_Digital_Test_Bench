一次A采用研究LP边界泵曲线；37°C恒温源边界接收一次回热，未动态模拟SP源泵、冷塔、分层罐或储冷耗用。因此只证明当前边界下的六柜适配行为，不得扩写为源侧/1800s/第二次故障或全18柜验证。

每步准稳态不可压缩水力 + 实际泵阀动态；不含水锤、管壁弹性、空化/NPSH。报告中的压差变化不能代替水锤/承压审查。未运行冻结M1，只保留先释放测量→控制→独立命令守卫→执行器→物理POST的因果顺序，不继承C3-C资格。
