# 泵止回阀混合互补求解

节点无可压缩储量时Bq=0。原泵曲线为H=H0*n²-Kq²。
泵和止回阀分别要求 q≥0, w=Kq²-H-(pi-pj)≥0, q*w=0。
开启时w=0；关闭时q=0且上游驱动力不足。串联元件共享节点KCL，不能分别截断后留下不守恒流量。

新方法把全部分支q与节点p同时作为未知量，使用Fischer-Burmeister函数
phi(a,b)=sqrt(a²+b²)-a-b=0，a=q/qd，b=w/100000。
半光滑Newton、解析广义Jacobian、尺度归一、最多100次迭代、24步有界线搜索及有界阻尼下降。
内部搜索试值不作为物理结果发布。最终同时检查KCL<原1e-6、压力方程<0.001Pa、互补残差及前向流量约束；不截断输出、不新增泄漏或修改拓扑。

原被动支路q=dp/[sqrt(K)*(dp²+r²)^(1/4)]，r=0.1Pa原值不变。
新方法使用该式的精确逆函数：s=Kq²，
dp=q*sqrt[K*(s+sqrt(s²+4r²))/2]。没有将原平滑损失替换成另一种物理律。
压力基准165/100kPa、0.1秒物理步长、泵曲线、效率、热交换、负载、测量和控制均不因算法修复而修改。

严格单调的支路损失约束流量解；闭合止回阀可使隔离压力区的压力非唯一。
报告Jacobian秩及pressure_nonunique，不把任意选取的隔离区压力当作真实被困液体压力。
本模型无可压缩性、定压设备、气囊、水锤及真实静高差；绝对压力和单侧失压结构安全不能由此认证。

数学依据为Benson/Munson的混合互补半光滑方法，采用自行实现的小型NumPy系统，不声称使用TAO或EPANET求解器。
