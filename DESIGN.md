# C2C Engineering Workbench

An engineer reviews equipment and tables on a desktop in daylight; use a light warm-neutral canvas with dark readable text and restrained copper accents, not a dark monitoring wall.

## Visual system

- Canvas oklch(0.97 0.008 80); sheet oklch(0.995 0.003 80); sidebar oklch(0.94 0.01 80).
- Ink oklch(0.25 0.015 60); secondary text oklch(0.47 0.015 60); copper action oklch(0.48 0.10 45).
- Semantic green/red/amber/blue reserved for stated result categories; chart temperature colors have an independent legend.
- System sans with Microsoft YaHei fallback; tabular numerals. Body 14px, section title 20px, page title 28px.
- 220px navigation, flexible content, 300px inspector. Tables and separated document sections, not identical card grids.
- Consistent 1px borders, 6px control radii, 32px primary page padding; no shadows required.
- Collapse navigation at 1000px, inspector below content at 1200px. Keep table columns readable with local scrolling.
- Native buttons, selects, labeled number inputs, focus ring and inline errors. No color-stripe alerts or gradient text.
