# 孟菲斯 V2：高温备用接管修复结果

结论：**项目协调器缺陷已修复并完成限定开发验证；热工及90秒连续性目标仍未满足。** 冻结M1、原物理模型和历史V1证据未修改。本次不是正式C3-C、设备选型合格、OEM校准、生产或硬件授权。

## 修复了什么

V1用同一个`failure_seen`同时阻止重复换源与后续高温备用接管，导致W1故障已处理后，即使出现高温且B有冷量也不能转B。V2把这两个一次性动作分开；历史故障锁仍然禁止回充，不清除Safety故障锁。新鲜测量、实际源路径确认、B估计冷量≥8.25m³、源泵停转/源阀关闭与负载阀关闭后换罐等限制保留。换同一个已运行冷源的罐，不再重复计入54秒备用冷源启动。

## 同轮fresh对照（WET_LOSS_STRATIFIED）

条件：18柜、2790kW IT / 2650.5kW入液，UA220kW/K为工程假设；240秒有限时域，dt0.1秒，t=30秒W1失效。45°C测点是**机柜二次侧入口**，不是回液、一次侧或GPU die。

最高温度下降1.192930°C，返回首达时延缩短29.1秒，但仍有1.701917°C超温、29.6秒时延超限。119.6秒是“可用源实际流量≥264m³/h且罐回流≤41.4448°C”的首次满足，不是持续稳定恢复保证；相应绝对时刻为149.6秒。源侧停泵/关阀/选罐/开阀完成于121.1秒，不能与负载侧113.7秒换罐混淆。240秒时入口43.059242°C，也不能抹去之前超温。

大白话：以前是“有备用冷量也不允许用”；现在允许并实际用了，但在温度已升高后才触发，物理换阀和热惯性仍需时间。软件动作链修好不等于容量与时序设计已经够用。没有擅自提前44.5°C触发点、提高45°C上限或放松冷量条件。

暖B与混合后无足够冷量的B均未触发接管、未实际换B；后者最高入口49.177987°C，不能把拒绝行为正确记成温控通过。网格40层相对基准最高温差+0.759043K、时间步细化差−0.010678K，属于观测到的离散化敏感性，不是OEM置信区间。
