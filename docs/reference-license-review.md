# Reference license review

Reviewed 2026-09-15. This is an engineering review, not legal advice. No source from these projects is copied into C2C-DTB. Mathematical methods described in public literature are independently implemented and attributed in project documentation.

The normal shallow-clone path was attempted twice and failed because the GitHub Git endpoint was unreachable. Read-only GitHub API archives were then used inside the ignored `references/` directory. Seven archives were validated and extracted. The Sustain-LC and Data Center Cooling Simulation archives truncated at large binary assets, so those two reviews use README, license, and source-tree evidence read through the GitHub API instead of claiming a complete local copy. This exception does not change the reuse decision.

## Gate decision

Production implementation is green-lit only for independent work based on standard conservation laws, control theory, and published methods. Any future proposal to copy source, data, FMUs, trained weights, or USD assets requires a file-level license review and an explicit approval record.
